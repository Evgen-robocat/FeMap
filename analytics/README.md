# FeMap — своя статистика посещений (v1.0.0)

Бесплатно: **Cloudflare Worker + D1**. Без cookie, без хранения IP.
Всё настраивается из браузера на телефоне, терминал не нужен.

## Что считается
- просмотры страницы и «уникальные» (в пределах суток, UTC);
- откуда пришли (только домен), страна, телефон/компьютер, язык интерфейса;
- какие слои включают на карте (id чекбокса).

Не считаются: заходы с localhost и локальных адресов, боты, браузеры с Do Not Track.

## Лимиты бесплатного тарифа (проверено по документации Cloudflare)
- Worker: 100 000 запросов в сутки.
- D1: 100 000 записей и 5 млн чтений в сутки, 5 ГБ.
- Каждый просмотр и каждое включение слоя — одна запись. При превышении лимита
  счётчик за этот день перестаёт писать, сайт при этом работает как обычно.

## Установка (один раз)

Названия пунктов в панели Cloudflare могут немного отличаться.

1. **Аккаунт.** Зарегистрируйся на dash.cloudflare.com (бесплатный тариф).
2. **База D1.** *Storage & Databases → D1 SQL Database → Create* → имя `femap-stats`.
   Таблицу создавать вручную не нужно, Worker создаст её сам при первом запросе.
3. **Worker.** *Workers & Pages → Create → Create Worker* → имя `femap-stats` →
   *Deploy* → *Edit code* → удали шаблон, вставь весь файл `worker.js` → *Deploy*.
4. **Привязка базы.** Worker → *Settings → Bindings → Add → D1 database*:
   имя переменной строго **`DB`**, база `femap-stats`.
5. **Переменные.** Worker → *Settings → Variables and Secrets → Add*:
   - `STATS_KEY` — тип **Secret**, длинный случайный ключ (это «пароль» к странице статистики);
   - `SALT` — тип **Secret**, любая длинная случайная строка;
   - `ALLOWED_ORIGIN` — тип **Text**, `https://femap.onrender.com`
     (адрес сайта без слэша на конце; со своим доменом — его адрес).
6. Адрес Worker'а смотри наверху его страницы, вида `https://femap-stats.ИМЯ.workers.dev`.
   Проверка: открой `…/health` — должно быть `ok`.

## Подключение к сайту
В `frontend/static/config.js` впиши адрес (без слэша на конце):

```js
var ANALYTICS_URL = 'https://femap-stats.ИМЯ.workers.dev';
```

Закоммить и запушь, Render обновит сайт. Заходы с localhost счётчик игнорирует,
поэтому для проверки открой сайт на его реальном адресе.

## Где смотреть
`https://femap-stats.ИМЯ.workers.dev/stats?key=ТВОЙ_STATS_KEY` — страница с графиком
по дням, источниками, странами, устройствами, языками и популярными слоями.
Периоды: `&days=7`, `&days=30`, `&days=90`. Данные в JSON: `/stats.json?key=…`.
Ссылку с ключом никому не отправляй. Для удобства добавь её в закладки браузера.

## Обслуживание
Чистка старых записей (раз в год, в D1 → Console):

```sql
DELETE FROM hits WHERE day < date('now', '-400 day');
```

## Приватность
Хранятся время, дата, хэш посетителя, событие, метка слоя, домен источника, язык,
тип устройства и код страны. Хэш считается как SHA-256(SALT + дата + IP + User-Agent),
меняется каждые сутки и не позволяет восстановить IP. Если хочешь, добавь на сайт
строку «Анонимная статистика без cookie».
