# 🌍 FeMap v3.0 — Interactive AE Projection Map

Интерактивная карта в азимутальной равноудалённой проекции (Azimuthal Equidistant).
Инструмент для визуализации картографических искажений и дебатов о форме Земли.

**🌐 Живой проект:** [femap.onrender.com](https://femap.onrender.com)

---

## 📖 О проекте

**FeMap** — это образовательный инструмент, созданный для демонстрации того, что так называемая «плоская карта мира» на самом деле является стандартной математической проекцией шарообразной Земли.

Проект позволяет:
* Менять центр проекции (любая точка на планете).
* Сравнивать реальные расстояния по сфере (Великий круг) с евклидовыми расстояниями на плоскости проекции.
* Визуализировать, как меняются очертания материков при смене точки 
---

## 🛠 Технологический стек

Проект разработан с учетом ограничений мобильной разработки (Android/Pydroid 3/Acode):
* **Frontend:** Чистый HTML5 / CSS3 / JavaScript (ES6+).
* **Engine:** [D3.js v7](https://d3js.org/) (Data-Driven Documents).
* **Data:** GeoJSON (Natural Earth data).
* **Deployment:** Render (Static Site).
* **Zero-Dependency:** Не требует Node.js, npm или сборщиков. Только статика.
