# 🌍 FeMap v7.2.8 — интерактивная карта в азимутальной равноудалённой проекции

Карта мира с изменяемым центром проекции и небесными объектами над ней.
Образовательный инструмент: показывает, что «плоская карта» — это обычная математическая проекция шарообразной Земли, и как меняются очертания материков при смене центра.

**🌐 Живой проект:** [femap.onrender.com](https://femap.onrender.com)

---

## ✨ Возможности

**Карта и измерения**
* Любая точка как центр проекции (клик по карте или поиск города).
* Сравнение расстояний по сфере (большой круг) и на плоскости проекции, линейка.
* Сетка, круги расстояний, города и метки (всё включается по отдельности).
* Языки интерфейса: русский, English, Deutsch (выпадающий список).

**Небо над картой**
* Подточки Солнца, Луны, планет (Меркурий … Нептун), звёзд и МКС; у каждого тела свой переключатель и своя подпись координат.
* Хвосты (следы) тел с плавными кривыми, длину настраивает пользователь.
* День/ночь, эклиптика, тропики, экватор, часовые пояса (25 цветных полос по 15° с подписями UTC±N).
* Тень Земли (умбра и пенумбра) вокруг точки, противоположной Солнцу, и узлы лунной орбиты Раху/Кету с линией орбиты Луны.
* Млечный Путь, созвездия зодиака с границами, подсветкой созвездия Солнца и необязательным Змееносцем.
* Выбор даты и времени (UTC) из календаря, кнопки «следующее солнечное / лунное затмение», ползунки года и суток.
* Транзиты Меркурия и Венеры по диску Солнца: список, карта видимости, путь планеты по диску Солнца.
* Анимация: «Суточное движение» — реальная скорость ×1 (1 с = 1 с), ×10, ×20, ×100 и плавный ползунок до ×50000; «Годовое движение · звёздные сутки» — шаг 24 ч и 23 ч 56 м на кадр. Длина хвостов считается по времени и не зависит от скорости.

**Мобильная версия**: работает на телефоне, масштабирование страницы отключено, карта увеличивается щипком.

## 🛠 Технологии

Проект сделан с оглядкой на разработку с телефона (Android, Pydroid 3, Termux, Acode) и **только на бесплатных сервисах**.

* **Frontend:** чистые HTML5 / CSS3 / JavaScript (ES6+), без сборки и npm.
* **Карта:** [D3.js v7](https://d3js.org/) (проекция, `geoPath`).
* **Астрономия:** [astronomy-engine](https://github.com/cosinekitty/astronomy) (положения тел, затмения), [satellite.js](https://github.com/shashwatak/satellite-js) (МКС, SGP4).
* **Хостинг сайта:** Render (Static Site).
* **Статистика:** собственная, на Cloudflare Worker + D1 (бесплатный тариф), без cookie, см. [`analytics/README.md`](analytics/README.md).

## 🚀 Запуск локально

```bash
cd frontend
python -m http.server 8000
# открыть http://localhost:8000
```

На телефоне в Termux то же самое, из папки `~/storage/shared/FEM/frontend`.
Заходы с localhost статистика не считает.

## 📊 Статистика посещений

Включается строкой `ANALYTICS_URL` в `frontend/static/config.js` (пустая строка — выключено).
Хранятся только время, хэш посетителя (меняется каждые сутки), страна, тип устройства, язык и домен источника. Не считаются localhost, боты и браузеры с Do Not Track. Подробности и установка: [`analytics/README.md`](analytics/README.md).

## 🗺 Данные и источники

* **Суша, границы, страны:** [Natural Earth](https://www.naturalearthdata.com/) (общественное достояние), масштаб 1:110 млн, поэтому мелкие детали упрощены.
* **Границы государств** показаны в границах, признанных международным правом. Из набора границ убраны «спорные» линии вокруг Крыма (NE_ID 1746708787 и 1746708837): Крым — территория Украины.
* **Млечный Путь:** контуры яркости из [d3-celestial](https://github.com/ofrohn/d3-celestial) (лицензия в `frontend/data/LICENSE-d3-celestial.txt`), упрощены для экономии трафика.
* **Созвездия зодиака:** границы IAU и звёзды из d3-celestial.

## 📝 Версии (кратко)

* **7.2.8** — щипок зума работает над ночной тенью: слои карты не перехватывают касания (`pointer-events:none`, кроме маршрутов и МКС); раньше палец на перерисовываемом элементе терял события, и зум шёл рывком или не шёл.
* **7.2.7** — зум и сдвиг карты больше не сбрасываются при изменении размера окна (на телефоне скрытие/появление адресной строки менялось высоту и возвращало карту в исходное положение); сохраняются масштаб и точка в центре экрана.
* **7.2.6** — режим проекции переименован по просьбе автора идеи: «Карта с изогнутыми меридианами» (ru), «Curved-meridian map» (en), «Karte mit gekrümmten Meridianen» (de). Внутренние id (`shilova-r/l`) не менялись.
* **7.2.5** — iPhone: нижняя панель настроек больше не «болтается» (горизонтальный скролл/отскок панели): `overflow-x:hidden`, `overscroll-behavior:contain`, страж `scrollLeft`. Диагностика: открыть сайт с `?dbg=1` — покажет элементы шире панели.
* **7.2.4** — линейка магнитится к точкам пересечения хвоста с меридианом (линии сетки каждые 30° и меридиан первой точки: вторая точка садится на ту же долготу, расстояние идёт по меридиану; галочка «🧲 магнит линейки: хвост × меридиан» под «Линейка расстояний»). Предел зума карты 50 → 150, чтобы попадать между близкими витками.
* **7.2.3** — бессрочные хвосты: галочка «∞» у хвостов Солнца и планет (у Луны её нет: за годы хвост Луны — сплошная каша и самая дорогая отрисовка). Хвост не обрезается по времени, а хранится до 6000 точек; дальше старая часть прореживается вдвое (последние 256 точек не трогаются). Если кадры идут медленнее ~150 мс, потолок точек автоматически снижается (до 700) — на слабых устройствах «∞» превращается в ~2 года. Хвосты теперь — постоянные path-элементы: устоявшаяся часть не пересоздаётся каждый кадр.
* **7.2.2** — быстрее хвосты в режимах «24ч» и «звёздные сутки»: история режется на куски по 32 точки, готовый path каждого куска кешируется (пересчёт только при смене проекции, центра, зума или размера), каждый кадр считается лишь свежий конец хвоста. Цикл анимации — на `requestAnimationFrame` с накоплением времени: кадр не чаще раза в 80 мс, при задержке пропущенные шаги дописываются в хвосты без перерисовки (до 3 за кадр), скорость «дней в секунду» не плавает. Замер (CPU ×6): кадр 61 → 29 мс.
* **7.2.1** — транзиты Меркурия и Венеры по диску Солнца (`static/transit.js`): список и кнопки «пред./след.» для каждой планеты, карта видимости (9 полушарий от первого до последнего контакта; граница в начале — зелёная, в конце — красная), путь подсолнечной точки с метками C1 / макс. / C4, мини-диск Солнца с путём планеты (из центра Земли, север вверху), строка в верхней панели и пометка «видно полностью / частично / не видно» для наблюдателя. Расчёт — `Astronomy.SearchTransit`.
* **7.2.0** — выбор проекции: азимутальная равнопромежуточная или «Меридианы Шиловой» (↻ / ↺). Расстояние от центра как в AE, но каждая точка поворачивается на угол s·arccos(ρ/π): при центре на полюсе меридианы — полуокружности, край диска не меняется. Работает со всеми слоями и «Видом из космоса» (`static/projection.js`). Расстояния на линейке и в подсказках маршрутов — по картинке выбранной проекции.
* **7.1.9** — часовые пояса: исправлена подпись «−9» над Южной Америкой, контуры у края диска (добавлены промежуточные точки), подписи без слова UTC и отдельной галочкой, опциональный циферблат по кругу от Гринвича.
* **7.1.7** — в «Виде из космоса» границы стран убраны совсем (галочка удалена).
* **7.1.6** — «Вид из космоса»: плавная анимация — текстуры перепроецируются только при смене центра/размера, ночная сторона — вторая картинка под маской из кругов (дешёвое обновление каждый кадр).
* **7.1.5** — «Наблюдатель» (точка, таблица) и «Круги видимости» разделены; заливка светом Солнца и Луны (яркость по фазе) — отдельные опции.
* **7.1.4** — «Вид из космоса»: границы стран скрыты (опция вернуть); наблюдатель: таблица высота/азимут в верхней панели, заливка кругов, значок тела в центре круга, подсказка режима выбора точки.
