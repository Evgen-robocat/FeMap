## ТЕХНИЧЕСКИЕ РЕШЕНИЯ (не менять без причины)

| Решение | Причина |
|---|---|
| GeoJSON вместо OSM тайлов | Тайлы искажаются при AEQD проекции |
| CRS ключ = AEQD:lat:lon | Leaflet кэширует статичный ключ |
| addedCities — только данные | Маркеры привязаны к карте, не к данным |
| html2canvas + 300мс задержка | Без задержки карта рендерится пустой |
| Статический сайт на Render | Не засыпает, в отличие от Web Service |
| /api/events для всех событий | Единая точка логирования |
